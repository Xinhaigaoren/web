# 上线部署指南（海林市高级中学校友会平台）

本文档说明如何把本项目正式上线：GitHub Pages 前台 + Render 后端 + Supabase(PostgreSQL) 数据库。

## 架构总览

```text
浏览器
 ├── GitHub Pages 静态站点（index.html / admin/ 等）
 └── Render 后端 API（server/server.js，Node.js + Express）
       └── Supabase PostgreSQL（表结构见 server/schema.sql）
```

## 一、准备

- GitHub 仓库：`zwx-hub/hailin-high-school-alumni`（默认分支 main）
- Supabase 账号：新建项目，拿到 `DATABASE_URL`（连接池串）
- Render 账号：注册 https://render.com

## 二、数据库初始化

1. 登录 Supabase 控制台 → 打开你的项目 → SQL Editor。
2. 把 `server/schema.sql` 全部内容粘贴执行（可重复执行；后端启动也会自动补齐新表，但建议先执行一次）。
3. 记录连接串：项目设置 → Database → Connection string（用 URI 形式 `postgresql://...`）。

## 三、后端部署（Render）

方式 A：手动创建（推荐，最稳）

1. Render → New → Web Service → 选择 GitHub 仓库。
2. 配置：
   - 环境：Node
   - 构建命令：`npm install`
   - 启动命令：`node server.js`
   - 实例类型：Free（够用；正式运营建议 Starter）
3. 添加环境变量（Settings → Environment）：

```text
DATABASE_URL=postgresql://...（Supabase 连接串）
TOKEN_SECRET=一段长随机字符串（必改，可用 openssl rand -hex 32 生成）
ADMIN_USER=admin
ADMIN_PASSWORD=强密码（必改）
PUBLIC_SITE_URL=https://zwx-hub.github.io/hailin-high-school-alumni
# 以下按需配置
WECHAT_APPID=
WECHAT_SECRET=
WECHAT_TEMPLATE_ID=
```

4. 部署完成后会得到后端地址，例如 `https://hailin-alumni-api.onrender.com`。
5. 验证：浏览器打开 `https://你的后端地址/api/health`，应返回 `{"ok":true,...}`。

方式 B：Render Blueprint（仓库已含 `server/render.yaml`，可在 Render 通过 Blueprint 导入）。

## 四、前端部署（GitHub Pages）

仓库已内置 `.github/workflows/deploy-pages.yml`，只要把代码推到 `main` 分支，Actions 会自动把仓库根目录发布到 GitHub Pages。

1. GitHub 仓库 → Settings → Pages → Source 选择 **GitHub Actions**。
2. 推送代码到 `main`，等待 Actions 运行完成。
3. 前台地址：`https://zwx-hub.github.io/hailin-high-school-alumni/`
4. 管理后台：`https://zwx-hub.github.io/hailin-high-school-alumni/admin/`

注意：`.nojekyll` 已存在，避免 Jekyll 干扰。

## 五、前端接口地址配置

`config.js` 中的 `API_BASE_URL` 要指向你的后端地址：

```js
window.HAILIN_CONFIG = {
  API_BASE_URL: "https://hailin-alumni-api.onrender.com"   // 改为你的 Render 地址
};
```

改完推送 `main` 即可自动更新线上站点。

## 六、启用微信登录 / 微信通知

1. 微信开放平台申请「网站应用」，拿到 AppID / AppSecret，授权回调域设为你的站点域名。
2. 后端环境变量填入 `WECHAT_APPID` / `WECHAT_SECRET`。
3. 微信模板消息：服务号申请模板消息后填写 `WECHAT_TEMPLATE_ID`（消息推送渠道选「微信」时会自动下发）。
4. 未配置时不影响邮箱注册登录，前端会提示「微信登录尚未配置」。

## 七、上线前必做安全检查

- [ ] `ADMIN_PASSWORD` 改为强密码（不要用默认值）
- [ ] `TOKEN_SECRET` 改为随机长字符串
- [ ] 访问控制：学信网截图等证明材料仅管理员可见（已实现，勿放开公开接口）
- [ ] 上传《隐私政策》《用户协议》页，并在注册/认证页注明数据用途
- [ ] 建议配置 HTTPS（GitHub Pages 与 Render 默认提供）
- [ ] 正式运营建议：学信网截图改存私有对象存储（R2/S3），数据库开启备份

## 八、日常更新流程

```bash
# 本地开发 → 推送到 main 即自动上线
git add -A
git commit -m "更新说明"
git push origin main
```

## 九、常见问题

- 后端返回 500 / 连接数据库失败：检查 `DATABASE_URL` 是否有效、Supabase 是否允许外网连接。
- 前端报 CORS：Render 后端已开启 CORS（允许任意来源）；如有问题检查 Render 日志。
- 图片上传 413：上传接口限制 10MB（express.json limit），前端限制 5MB 图片。
- GitHub Pages 更新慢：Actions 完成后等待 1-2 分钟生效。
